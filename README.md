# Contemplative Neuroscience

A curated, open knowledge base for the neuroscience of meditation and contemplative practice,
with an interactive explorer and an on-device paper finder built on a contrastive language
model (CLM).

**[Open the interface](https://cation21.github.io/contemplative-neuroscience/)** · [Knowledge base](#knowledge-base) · [Paper finder](clm/README.md) · [Contributing](CONTRIBUTING.md)

## What's here

| Part | What it does | Where |
|---|---|---|
| Knowledge base | Papers, open datasets, tools, literature APIs, labs and core concepts, as plain YAML | [`knowledge/`](knowledge) |
| Explorer | Search and filter everything in the knowledge base | [`site/`](site) → *Explore* |
| Paper finder | Paste an abstract or a rough idea and get the closest papers, ranked by a contrastive text encoder running in your browser | [`site/`](site) → *Find papers*, [`clm/`](clm) |
| Map | 2D map of the paper collection by embedding similarity | [`site/`](site) → *Map* |
| CLM pipeline | Build a corpus, fine-tune the encoder, evaluate it and export it for the browser | [`clm/`](clm) |
| Landscape notes | What changed in 2024–26: datasets, EEG foundation models, meta-analysis tools, API changes | [`docs/landscape-2026.md`](docs/landscape-2026.md) |

### Privacy

The paper finder downloads a small encoder once (all-MiniLM-L6-v2, int8, a few tens of MB) and
runs it locally with [Transformers.js](https://huggingface.co/docs/transformers.js). What you
paste is never sent anywhere. The optional *Search beyond this collection* button is off by
default; when used, it sends only extracted keywords to Europe PMC (or OpenAlex, if you add
your own key) and re-ranks the results on your device.

## Run locally

```bash
python -m http.server -d site 8000     # then open http://localhost:8000
```

Edit the YAML in `knowledge/`, then regenerate the site data and the tables below:

```bash
pip install pyyaml
python scripts/build_kb.py
```

### Literature and data infrastructure

| Resource | Kind | Auth | Notes |
|---|---|---|---|
| [Europe PMC](https://europepmc.org) | literature | none | No key needed. resultType=core returns abstracts, MeSH terms and licence info. Used by the finder's live search and the corpus builder. |
| [OpenAlex](https://openalex.org) | literature | free-key | Since 13 Feb 2026 the API needs a free key (about $1/day of free usage; keyless is a small demo quota). Abstracts come as an inverted index. Best for citation pairs. Bulk snapshot remains free on S3. |
| [Semantic Scholar API](https://www.semanticscholar.org) | literature | none | Recommendations endpoint suggests recent papers from positive/negative seed papers. Low anonymous rate limits; request a key for heavy use. |
| [PubMed (NCBI E-utilities)](https://pubmed.ncbi.nlm.nih.gov) | literature | none | MeSH term "Meditation" is the cleanest filter. Optional key raises rate limits. |
| [arXiv](https://arxiv.org) | literature | none | Metadata (including abstracts) is CC0, so it is safe to redistribute in the corpus. |
| [bioRxiv / medRxiv](https://www.biorxiv.org) | literature | none | Where many neuroimaging meditation papers appear first. |
| [OpenNeuro](https://openneuro.org) | data-archive | none | Every dataset passes BIDS validation; most are CC0. |
| [NEMAR](https://nemar.org) | data-archive | none | Run EEGLAB/MNE pipelines on OpenNeuro electrophysiology without downloading. |
| [DANDI Archive](https://dandiarchive.org) | data-archive | account | Mainly animal and intracranial data; relevant for mechanistic work. |
| [Zenodo](https://zenodo.org) | data-archive | none | Hosts several meditation EEG datasets, including the Delorme meditation set. |
| [Hugging Face Datasets](https://huggingface.co/datasets) | data-archive | none | Increasingly where EEG benchmarks are released. |
| [NeuroStore / Neurosynth](https://compose.neurosynth.org) | meta-analysis | account | Basis for custom meta-analyses of meditation fMRI. |
